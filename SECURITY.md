# Security policy

Please do not open a public issue containing credentials, webhook URLs, API keys, service-account files, or private news data.

Report a suspected vulnerability privately through GitHub's **Security** tab when private vulnerability reporting is enabled. Otherwise, contact the repository owner without including working secrets in the first message.

Before publishing a release, run the automated tests and dependency audit, and confirm that `.env`, `config.yaml`, service-account JSON files, databases, logs, downloaded models, and runtime binaries are not tracked.
